## El protocolo de 90 minutos

No necesitas apps mágicas. Necesitas un bloque serio y reglas simples.

### Reglas

- Modo avión
- Una sola pestaña
- Objetivo por escrito

```bash
# Señal de inicio del bloque
printf "deep-work:start %s\n" "$(date -Iseconds)"
```

## Lo importante

No persigas horas, persigue sesiones de calidad.
